# Utilities API

Calendar, backtest and messaging resources provide market schedules, historical SIP analysis and opt-in alert delivery.

| Endpoint | Purpose |
|---|---|
| [Holidays](holidays.md) | Read exchange holidays |
| [Timings](timings.md) | Read the market schedule for a date |
| [Telegram](telegram.md) | Configure and operate Telegram delivery |
| [WhatsApp](whatsapp.md) | Send a WhatsApp notification |
| [Slack](slack.md) | Post a message to your Slack channel |
| [Discord](discord.md) | Post a message to your Discord channel |
| [SIP Backtest](sip-backtest.md) | Simulate systematic investments without placing orders |
