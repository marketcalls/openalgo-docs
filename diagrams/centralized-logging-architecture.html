Centralized logging

Every log line is cleaned of secrets before it is written anywhere

All OpenAlgo code and the libraries it uses log through one root logger. A redaction filter removes keys, tokens and passwords, then three outputs write the same message to the console, a daily file and an errors-only file.

Runs in every process: gunicorn worker and WebSocket proxy child
