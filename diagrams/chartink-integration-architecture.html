Chartink integration

Scanner alerts become paced orders through the normal order path

A Chartink alert is checked and turned into orders, which wait in a queue and are sent at a safe pace through the same REST API as every other order. Intraday strategies are squared off on schedule.

The webhook never calls the broker directly. Queued orders re-enter OpenAlgo through /api/v1, so Action Center, sandbox mode and order checks apply exactly as for any other order. Follow the numbers: left to right along the top, then back right to left along the bottom.
