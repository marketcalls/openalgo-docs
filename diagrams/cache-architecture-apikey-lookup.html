API key check

Most API key checks are answered from memory

Every API call carries your API key. OpenAlgo first asks two small caches whether it has seen this key recently; only an unknown key goes through the slow, secure Argon2 check against the database. The answer is then cached, so the next call is instant.

Known keys stop at step 3 or 4 with no hashing work. The expensive Argon2 check runs only for a key this process has not cached yet, and failed keys are logged so repeat offenders can be banned by IP.
