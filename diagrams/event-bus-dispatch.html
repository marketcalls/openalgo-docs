Event bus

One order event, up to six listeners, zero waiting

When an order is placed or updated, the code that did it just drops an event on the bus and moves on. A small worker pool then tells the logs, the web screen, Telegram, WhatsApp, live WebSocket clients and the strategy book, each one isolated so a slow or failing listener never blocks your order. Some listeners only take certain events.
