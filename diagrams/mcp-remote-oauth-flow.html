Remote MCP sign-in

An AI app gets only the permissions you sign in and approve

A hosted AI client (for example a web chat app) connects to your OpenAlgo MCP server with standard OAuth. You log in to OpenAlgo, see which permissions (scopes) it asks for, and approve. From then on every tool call is checked against what you granted and logged.
